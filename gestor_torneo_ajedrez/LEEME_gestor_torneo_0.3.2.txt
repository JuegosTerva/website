# Gestor de torneos de ajedrez · Juegos Terva
## Versión 0.4.0

### Archivos que utiliza la página
- `index.html`: interfaz del gestor.
- `gestor_app_0.3.2.js`: lógica de interfaz, captura, revisión de primera ronda y distribución de mesas.
- `motor_suizo.js`: validación, resultados, clasificación y desempates.
- `styles.css`: estilos.

`README_motor_suizo.md` documenta el motor. `PRUEBAS_0.4.0.txt` resume las pruebas técnicas realizadas.

### Novedades 0.4.0
1. **Doble incomparecencia 0–0:** se puede elegir al capturar el resultado. Ambos reciben cero puntos y queda marcado como resultado administrativo.
2. **Revisión de primera ronda:** la aplicación presenta una pareja candidata. Puedes confirmar la pareja o pasar blancas/negras al final de la fila. Las parejas confirmadas quedan guardadas y no se recalculan. Cada participante puede pasarse una vez durante la revisión. Si solo quedan dos, se confirma esa pareja. El BYE, si se necesita, se asigna automáticamente con las reglas actuales y se muestra aparte.
3. **Filtro de captura:** muestra todas las partidas, solo pendientes o solo capturadas. Incluye contador de capturadas y pendientes.
4. **Distribución física mixta:** selecciona una ronda confirmada o cerrada de cada categoría que jugará en la jornada. La aplicación intercala una partida de cada categoría y asigna ubicaciones consecutivas: mesa 1/tablero 1 hasta mesa 25/tablero 4.
5. **Localización de participantes:** busca por ID o nombre en la distribución general. La exportación CSV genera una fila por jugador con mesa, tablero, categoría, ronda, color y rival.
6. **Capacidad:** hay 100 ubicaciones. Si se seleccionan más de 100 partidas, las excedentes siguen visibles y exportables como `Sin asignar`; no se descartan.
7. **BYE:** se lista aparte porque no ocupa tablero.

### Actualizar en GitHub Pages
1. Antes de actualizar, descarga un respaldo JSON desde el gestor y conserva una copia fuera del dispositivo.
2. En la carpeta del repositorio donde está el gestor, sustituye estos cuatro archivos conservando exactamente sus nombres: `index.html`, `gestor_app_0.3.2.js`, `motor_suizo.js` y `styles.css`.
3. Haz commit en la rama que publica GitHub Pages.
4. Espera a que termine la publicación y vuelve a abrir la página. El HTML carga JS y CSS con `?v=0.4.0` para evitar caché de versiones anteriores.
5. No borres los datos del sitio ni cambies la clave localStorage `juegosTerva.gestorAjedrez.v03`; así se conserva el evento guardado en ese navegador.
6. Verifica primero con una copia de respaldo o un torneo de prueba. No uses una actualización no probada como único registro de un torneo activo.

### Uso de la revisión de primera ronda
- Inicia la categoría y genera la ronda 1.
- Revisa la pareja candidata y el color asignado.
- Pulsa `Confirmar pareja` para bloquear ese enfrentamiento, o pasa blancas/negras al final de la fila.
- El jugador pasado no puede volver a pasarse en esa misma revisión.
- Cuando todos estén emparejados, confirma la ronda para habilitar la captura de resultados.
- La revisión parcial se guarda en el navegador y puede continuar después de recargar la página.

### Uso de la distribución física
- Abre `Distribución general de mesas` en el panel del evento.
- Elige una ronda confirmada o cerrada de cada categoría que jugará en esa jornada.
- Pulsa `Generar distribución mixta`.
- El orden alterna una partida por categoría en cada vuelta y luego asigna las ubicaciones en secuencia. Puedes elegir `No incluir esta categoría` si no jugará en esa jornada.
- Busca por ID o nombre para localizar la partida.
- Exporta el CSV para tener una lista por participante.
- Si cambias las rondas seleccionadas o los emparejamientos, genera una nueva distribución. La distribución guardada es una fotografía independiente; no modifica emparejamientos ni resultados.

### Consideraciones
- Cada categoría conserva sus propios participantes, puntuación, resultados y clasificación. La distribución física solo reúne las ubicaciones.
- Los datos se guardan en `localStorage` del navegador. El almacenamiento no se sincroniza automáticamente entre dispositivos.
- El emparejamiento sigue siendo un suizo simplificado de esta aplicación; no es un emparejador oficial certificado FIDE.
